# 24. 原生会话资料处理与交付

> 状态：Proposed。
> 范围：对话页面内处理明确选择的纪要与任务表，下载报告和汇总，可另行发送站内提醒请求。
> 不包含：服务器附件库、历史产物、自动续办、办公连接器、通用代码执行和外部发送。
> 阶段：#158；行为以 OpenSpec 为准。

## 1. 为什么不做办公 Run

一次统计和导出不需要多轮代理执行。把输入和输出做成会话资源，会连带引入所有权绑定、持久化、撤销规则、运行协议和私有快照恢复。这里的文件是页面上的一次输入，不是可恢复的服务器资源。页面提供结果，但不会伪装成历史里永远可重新下载的附件。

复用 `csv-parse`/`csv-stringify` 的浏览器版本与标准 `File`/`Blob`。DeepSeek 的 [Files API](https://api-docs.deepseek.com/guides/document_parsing/#text-files) 对纯文本上传不收费，但仍按模型 token 计费，只解决模型读取，不提供确定性计算或成品交付；对本阶段纯文本原件反而增加外部副本。Google Sheets/Drive 可按各自合同处理表格和导出，但会引入新的授权连接和存储目的地。该用例不增加新的供应商。

## 2. 处理与下载

对话页提供独立资料面板。文件选择、校验和下载不发送聊天消息、不新建 Run、不写工作区。CSV 使用 UTF-8（允许 BOM），上限 1 MiB、5000 条记录，列固定为 `task_id,title,owner,due_date,status`，可重排。引号、多行字段与转义交给库；非法编码、不齐记录、缺列、多列、重名表头、空或重复 ID 不静默跳过。

用户明确选择一个公历截至日，不从服务器时区或文件猜测。仅 `todo`/`in_progress` 且合法 `due_date` 严格早于截至日才逾期；缺失日期、非法日期和非枚举状态分别记录。负责人去首尾空白后分组，未分配组与字面名称区分。Markdown 报告和 CSV 汇总使用同一计算结果，统计不来自模型。导出 CSV 将危险公式前缀降为文本。

报告和汇总从浏览器直接下载。清除或替换材料使旧的页面结果失效；刷新后需要重新选择文件；没有服务器链接可撤销，也不能收回已经下载的副本。

## 3. 可选纪要摘要

用户选择生成摘要并确认资料送往本人默认模型后，`POST /api/v1/model-providers/actions/summarize-notes` 接收 `{notes}`（UTF-8 48 KiB 上限），返回 `{summary}`。这是单次、只读的文本转换，不是第二套 Harness。使用既有身份、CSRF、模型配置、受控出站与有限超时；只发本次纪要文本，不发原 CSV、会话历史、文件名或记忆；没有工具、自动重试和可恢复的半成品。只有完整模型结果可进入报告。取消、切换材料或失败不应将过时/不完整摘要附入报告，也不影响已完成的统计与下载。

Along 不持久化请求或摘要，不会把纪要送进对话快照。已经发往供应商的内容受该供应商条款约束，清除本页不等同于删除供应商副本。没有默认模型时不回退到其他模型。

## 4. 站内提醒与验证

提醒从相同页面沿既有对话入口单独提交，内容由用户明确输入。文件内容、模型摘要和任务截止日期都不是提醒授权。时间资格、取消、幂等、澄清和创建回执由既有链路负责；补提醒时间不需要重做文件。

浏览器验收默认可见入口、选材、确定性边界、两种实际下载和普通对话互不影响。受控模型在真实 HTTP 路径验证身份、限额、只读、发送内容和失败分支。真实模型质量及站内通知到点取证与代码验证分开，不用受控响应冒充真实供应商。
