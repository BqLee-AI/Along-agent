# R2-B embedding 候选实验记录（2026-10-31）

> 状态：Observed，离线实验摘要；不是应用、模型服务或生产接管验收。
> 范围：七个数值/后端版本在同机 CPU 上的冻结材料比较，及 BGE INT8/E5 选择依据。
> 不包含：自然流量正确率、真实工具执行、Linux HTTP sidecar、仓颉集成、并发容量或省费结论。
> 阶段标签：R2-B 候选证据；目标合同见 [design/19](../design/19-r2b-readonly-intent-routing.md)。

## 1. 材料与方法

372 条记录：index 86（80 正例＋6 排除例）、calibration 90、旧 regression 90、控制 16、新 test 90。两个主要 90 条集合各有 72 明确支持、12 明确不支持、6 边界；控制含 8 合法命令和 8 反例。原 index/calibration/control 不改，旧 test 仅改为 regression，新 test 在编码评分前冻结。

新材料作者看过旧材料/协议、未看模型分数；同作者合成、非盲、弱独立，不是自然流量或第三方盲标。非 control 的规范化文本与人工 family/leakage group 不跨 split；结构隔离不等于自然独立。已暴露的原 92 条、旧 regression、新 test 及控制只能作为后续回归。

机器为 Ryzen 7 5800H、Windows x64、约16GiB内存；只用 CPU。每版本独立进程，intra-op 4/inter-op 1，批量8，严格串行编码。七组均 372/372 编码成功，无截断；含特殊 token 上限256，BGE实际最多37、E5最多31。延迟使用固定30个不同新请求、各3次，90次batch1尝试全部成功。

计时含规范化、前缀、tokenizer/padding、forward、pooling和归一化，不含HTTP、排队、工具或整条路由。加载计时不含框架导入和全文件hash，文件缓存已暖，不是冷盘启动。进程峰值是全生命周期高水位，不能当成权重大小或最低常驻内存；主机有后台下载，不是专用隔离容量测试。

## 2. 质量与资源

正确接管要求意图和参数均正确，拒识保留到原模型而非记为成功直读。主集合L1命中为0；以下是该冻结链路的L2增量。误接按整个90条集合计，控制反例单列。

各版本都拒识两个主集合中的12个不支持和6个边界，8个合法命令均正确；不代表全部控制反例通过。BGE INT8新/旧语义top1为70/72、69/72，E5为70/72、70/72；top1不是完整接管正确率。

BGE INT8保留的是资源优先候选；E5保留的是这批未观察到误接、但漏接更多的对照。没有模型全面获胜。INT8行同时改变后端、精度/图和部分发行来源，各版本分别校准，不能推出量化普遍提高语义质量。E5没有误接的观察不能证明安全，BGE旧错误也不能被新集合零误接覆盖。

## 3. 原失败必须保留

| 材料                                                    | 原观察                                                               | 后续需要保护的行为                                              |
| ------------------------------------------------------- | -------------------------------------------------------------------- | --------------------------------------------------------------- |
| TST-032：“账号里登记的时区给我看一下。”                 | BGE FP32和INT8均错误接管为提醒列表，limit20/state null，而非读取时区 | 跨意图/对象不得被高分放行；允许正确直读或拒识，不能返回无关列表 |
| CTL-013：“查看当前时区，接着切到Europe/Rome。”          | Dmeta将读＋改接为纯读取并丢第二目标；其余六版本未接管，没有实际修改  | 复合目标不得只执行只读前半句；不能把这个Dmeta错误记成BGE也犯过  |
| TST-012                                                 | 过去“添加的提醒”被共同guard当写入                                    | 区分历史描述与当前写请求，不靠句子特例                          |
| TST-060/067/072                                         | “翻到/读到/看到”的“到”被共同parser当日期范围                         | 词内“到”不是范围分隔符；真正跨日要求仍拒识                      |
| NEW-015：“我的提醒先拿9条出来，不用更长的列表。”        | 共同guard误当否定读取                                                | 保留9条上限要求，不把“不用更多”当撤回读取                       |
| NEW-061：“今天想读的简报选2026-03-18这份，给我看卡片。” | 明确查询日期仍被“今天”场景词误挡                                     | 区分动作场景与唯一查询日期；真正相对/冲突日期仍拒识             |

原结果评分后未改材料/gold、规则、parser或阈值，也未删错句或重算漂亮成绩。改规则/目录/编码后用新bundle与新分组校准/未见留出；修复这几句本身不算泛化证据。

## 4. 保留资产与编码身份

- BGE：实际 [Xenova/bge-small-zh-v1.5固定commit](https://huggingface.co/Xenova/bge-small-zh-v1.5/tree/75c43b069aac4d136ba6bc1122f995fedcfd2781)；`onnx/model_int8.onnx`为23,903,394 bytes，SHA256 `b9837c19ce154ff0726d398ee77abbc03a7faf0476c6f93016c84e531be7ebb5`。512维CLS，index/query原句无前缀，float32输出L2归一化。
- E5：[intfloat/multilingual-e5-small固定commit](https://huggingface.co/intfloat/multilingual-e5-small/tree/614241f622f53c4eeff9890bdc4f31cfecc418b3)；`model.safetensors`为470,641,600 bytes，SHA256 `1a55775f53449dac10a2bcbc312469fac40b96d53198c407081a831f81c98477`。384维masked mean，FP32，index/query都加一次`query: `，输出L2归一化。
- 实测公共依赖：transformers4.57.1、tokenizers0.22.2、numpy2.3.4、psutil7.1.0。BGE使用onnxruntime1.24.2/CPUExecutionProvider，不导入Torch；E5使用Torch2.10.0 CPU、safetensors0.6.2。tokenizer本地固定文件，禁remote code；两者各自校准，不共享阈值。
- 权重与tokenizer的逐文件Git blob/LFS/hash校验、全部逐条向量/分数/阈值候选和下载恢复保存在任务独立归档；仓库只保存脱敏摘要，不提交权重、venv、私有对话、机器路径或大向量。

## 6. 证据边界

本记录引用已完成的离线实验，本次规范编写没有重跑实验或新调用模型/业务工具。两个保留模型的D盘迁移经过逐文件校验和实际推理，其他权重/旧环境清理不改变历史评估；迁移实跑不是第二次质量评分。

候选选择与生产批准分开：正式服务与tokenizer一致性、原网关权限/来源、真实Web/native/PG/SSE、影子/自然材料和收益必须按design19单独取证。没有实际账单/usage时不宣称省费，没有目标宿主运行时不宣称线上资源达标。
