# #167 工具供给对照实验（2026-11-23）

## 结论

本轮不推进 `propose-on-demand-tool-supply`，不改变生产 Schema 供给，不新增目录平台。真实模型样本累计逻辑输入体积下降 **6.77%**，模型轮次从 **13 增至 17**；受控对照下降 **1.78%**，轮次从 **13 增至 19**。均未达到实验开始前冻结的 20% 累计体积收益门槛。这个否定结论只针对本轮候选和目录，不否定更大目录或其他供给策略。

关联：Refs #167。基线 `ea01db0452fa53509958412a14734901acfdbf60`。验收负责人：本项执行 Agent；未合并、未修改生产合同。

## 合同与真实目录

- `docs/design/09-agent-runtime-and-checkpoint.md` §1、§5：仓颉唯一循环；资格为冻结产品策略与当前授权交集，每次调用经原网关核验。
- `docs/design/18-r2a-harness-context.md` §2、§5：区分累计输入与首轮、体积与 token；旧 Run 不因新工具扩权。
- `openspec/specs/tool-gateway/spec.md`「能力资格与语义委托各有来源」「当前访问资格与提交审计」：发现/可见性不形成授权，owner、attempt、停止、资源与真实效果仍由原网关检查。
- 实际描述直接导入 `apps/api/src/agent/tools/catalog.ts`，不复制或扩充虚构工具。组合为 delegation 描述、compact-memory 描述和原消息回查，共 **19 项**；生产装配参照 `apps/api/src/agent/runtime/context.ts#buildHarnessStart`。
- 这是能力丰富的**受控冻结集合**，不是从个人生产 Run 导出的权限快照、默认资格或自然流量分布。特意保留全部候选作为 Schema 缩减的有利上界；包括实际请求中可能根本不会获准的 request-bound 飞书读取。无资格场景另冻结为三个只读工具。实验不声称完整复刻 profile/接入/登记的生产准入过程；该窄集合仍使用原目录的 delegation 列表描述，而生产在缺少取消资格时会选择 legacy 列表描述。
- 文件任务实际读取仓库的 `docs/demo/fault-injection-smoke.md` 作为材料；创建和新回读发生在隔离内存夹具，不写业务工作区。偏好、提醒、简报是固定虚构夹具。真实资料目录、TS MCP、文件写入、PG、native 和 Web 的端到端行为**未验收**。

## 候选、门槛与成本

对照保持请求、资格集合、原始工具描述/参数 Schema、业务夹具和最多 8 个模型轮次一致，每次仅一个业务调用：

1. **整组**：每轮提供冻结集合内全部 Schema。
2. **按需**：初始只提供 `tool_search`，其描述包含资格内全部工具的名称和原始说明，但不含参数 Schema。模型按名称一次装载最多 4 项；下一轮才能调用。成功装载在本实验 Run 内累积，未命中返回空，不回退全局目录。搜索观察中的完整 Schema 与之后 `tools` 中的 Schema 都如实纳入体积。

这是最小的“目录摘要 + 延迟 Schema”，不是语义搜索：不引入 embedding、向量库、插件市场、注册接口、外部发现、缓存服务或资格变更。完整目录摘要避免凭空猜工具名，也避免用任务标签偷偷替模型挑工具。代价是长说明仍需每轮发送；更激进的说明裁剪需要另外验证发现质量。

预先固定的进入最小规格门槛见脚本 `threshold`：累计逻辑输入体积至少下降 **20%**，观察到的任务成功不退化，新增模型轮次的中位数不超过 **1**、最大不超过 **2**。20% 是本轮工程取舍，不是产品 SLA：小幅字节收益不足以支持 native/transport/预算/恢复的新状态与额外模型请求。达到也只允许提出规格，不能据此直接实施或宣称生产收益。

## 方法与证据分层

实现：`scripts/experiments/tool-supply.mjs`，回归覆盖：`scripts/test/tool-supply.test.ts`。

- **受控协议模型**：动作由确定性策略提供。正向场景一次装载全部所需工具；缺失、无资格场景主动搜索一次，验证空结果。它只说明实验器的反馈与成本，不说明真实模型会如何选择。
- **真实模型选择**：宿主 `completion(model='default')`，6 个任务各跑整组/按需一对，共 **12 个轨迹、30 次实际成功返回的模型调用**。模型自己选择工具、参数、是否搜索与何时停止，未提供 `sequence` 或答案。每对并行执行，不是随机交叉或统计显著性试验；只有一次重复。宿主没有在该接口公开可核对的具体模型版本或 provider usage，不声称固定模型可重现或低错误率。
- 宿主接收的提示是逻辑请求的 JSON，要求返回动作 JSON；这是真实 LLM 输出，但**不是 native function calling、Along TS transport 或正式 Harness 消费者**。全部业务效果仍是受控夹具，不因模型真实就称为真实业务完成。
- 计量为每轮 `JSON.stringify({messages,tools,parallel_tool_calls:false})` 的 UTF-8 bytes，包含完整历史、工具结果、搜索结果、摘要和工具 Schema；累计所有轮次，包括最终回答前的请求。`schemaBytes` 是其中的工具数组部分，不能代替全输入。不是宿主实际 HTTP body、token、计费、缓存命中或生产时延。provider 输入 token/usage 为 **unknown**，不按 bytes 换算。
- 每轮 `elapsedMs` 是宿主调用等待时长，包含宿主调度，不作生产延迟或 p95 结论。模型最终回答是输出，不计入后续不存在的输入。
- 先前尝试将未等待的 completion promise 跨 eval 调用保留，12 个任务均返回 `Run no longer active`，零模型结果，已报告工具异常。该批不计作模型质量失败，也不混入上述配对体积。之后在同一次 eval 生命周期中等待每对，得到下表结果；失败批计数保留于 JSON。

## 实测结果

`bytes` 为累计逻辑输入体积。轮次包含最后一次回答；搜索调用计入模型轮次。

| 场景                     |  整组 bytes | 按需 bytes（真实模型） |  累计缩减 | 整组 / 按需轮次 | 实际业务选择                                     |
| ------------------------ | ----------: | ---------------------: | --------: | --------------: | ------------------------------------------------ |
| 简单：默认时区           |      23,640 |                 21,712 |     8.16% |           2 / 3 | get_user_prefs                                   |
| 简单：活动提醒           |      23,777 |                 25,120 |    -5.65% |           2 / 3 | list_tasks                                       |
| 跨工具：时区与简报       |      35,927 |                 32,163 |    10.48% |           3 / 4 | get_user_prefs、read_brief_cards                 |
| 跨工具：全文复制并新回读 |      91,171 |                 87,971 |     3.51% |           4 / 5 | workspace_read、workspace_create、workspace_read |
| 查找不到：发送邮件       |      11,792 |                  6,802 |    42.32% |           1 / 1 | 明确不可用，未搜索、未调用业务工具               |
| 无资格：强求读取文件     |       2,332 |                  2,108 |     9.61% |           1 / 1 | 明确无资格，未搜索、未调用业务工具               |
| **合计**                 | **188,639** |            **175,876** | **6.77%** |     **13 / 17** | 两种供给均 6/6 通过夹具判据                      |

真实模型的 4 个正向按需场景各批量搜索一次，未出现拒绝/参数错误或无关业务调用；负向场景直接依据目录说明不可用，不能据此宣称真实模型验证过空搜索结果。资格拒绝、空结果与调用不能绕过装载的行为由受控轨迹/回归用例证明，**不是生产网关安全验收**。

受控对照：整组 **188,639 bytes / 13 轮**，按需 **185,280 bytes / 19 轮**，缩减 **1.78%**，两种供给均 **6/6**。两种负向场景按需分别为 **13,847**、**4,467 bytes**，各 2 轮；差异来自受控策略强制搜索，而非真实模型失败。正向四场景的实际业务调用和体积在本样本中恰好与真实模型一致；两者仍是分开生成的证据。

首轮常规集合缩减 **41.97%–42.60%**，不是累计收益。真实模型额外轮次为 `[1,1,1,1,0,0]`，中位数/最大均为 1；成功判据要求读取事实出现在答案，文件输出逐字等于来源并有独立新回读。最终文本只做有限事实/状态检查，不是通用答案质量评测。记忆、编辑/冲突、提醒创建/取消、批准恢复和分页任务未覆盖。

## 复现与核验

仓库实验不读取 `.env` 或个人配置，无需 DB、模型 key、网络或安装 workspace 依赖。正式项目锁定 Bun 1.4.2；本轮首次回归曾使用宿主 Bun 1.4.4，交付核验使用 1.4.2，具体结果见下节。

```sh
bun scripts/experiments/tool-supply.mjs controlled
bun scripts/experiments/tool-supply.mjs replay docs/verification/tool-supply-167-controlled-2026-11-23.json
bun scripts/experiments/tool-supply.mjs replay docs/verification/tool-supply-167-model-2026-11-23.json
bun test scripts/test/tool-supply.test.ts
```

两份 JSON 保存来源 SHA-256、每轮逻辑请求哈希、动作、选择、轮次、体积和成功判据结果；来源变化或回放请求/结果不一致会失败。回放验证可重建性，**不会重新调用真实模型**。工具输出由固定夹具及版本化源文件重建，不以模型答案冒充工具结果。

重新采样可在具备 `completion` 的宿主 eval JS 中运行下面的结构，必须在同一个 eval 调用内等待所有模型结果。`completion` 属于本次宿主 API，普通 Bun CLI 不提供；未额外添加 provider/凭据平台。另一个宿主可向 `runSuite` 传入自己的真实模型回调，但必须记录模型与适配器差异。

````js
const exp = await import('<工作树绝对路径>/scripts/experiments/tool-supply.mjs');
const evidence = await exp.runSuite(async (request) => {
  const handle = await completion(JSON.stringify(request), {
    model: 'default',
    system:
      'Act as the model in the supplied isolated tool experiment. Return only the next action JSON required by its system message, without markdown. Tools are represented as data; do not use host tools.',
  });
  const text = await handle.wait();
  return JSON.parse(text.replace(/^```(?:json)?\s*|\s*```$/g, ''));
});
// 按宿主文件接口保存 evidence；不打印/保存凭据。
````

上例串行采样；本轮每个任务的两种模式并行，顺序和宿主排队会改变时长与随机结果。逐轨迹离线回放才是本轮数值的确定性复现方式。脚本中的受控 `sequence` 仅供受控策略与评分，不发给真实模型。

## 交付验证与边界

- 实验器回归保护三项可观察失败：无资格搜索不返回 Schema、直接越权不执行；创建后缺独立回读不得算成功；不存在工具搜索不得替换为其他能力。
- 策略是未知能力先探索、再保护实验器边界，不声称 TDD；生产行为未变，不需要新 OpenSpec。
- 本项未修改生产源文件、合同、迁移、配置、模型路由或外部账户；未触碰市场/供应商/推送/计费等 Deferred。
- 不创建生产最小规格或草稿 PR：累计收益门槛未达到。重新打开设计的证据应来自实际资格集合显著变大，或同样完整计费/计轮的更小目录摘要候选达到上述门槛；还须补正式函数协议、native、真实网关与任务材料验证。不能凭首轮缩减或本轮 6/6 直接上线。
