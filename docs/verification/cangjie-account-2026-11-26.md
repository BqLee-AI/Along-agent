# 仓颉账户与模型设置验收

`host-runtime` 镜像 `sha256:cf666b89fe6c72f11e1691b4cd91883acdb62b0ccbbdf8057f7b4b3b0f05ba1c` 包含账户入口迁移。`scripts/ci/host-account-smoke.ts` 在这个镜像中分别启动仓颉和 TS 入口，使用独立 PostgreSQL 16 和禁止外网访问的 Docker 网络。

- Next API 代理经真实 HTTP 验证登录、退出、邀请接受、密码重置与模型配置写入。会话可读取 `/me`，退出后的多条清除 Cookie 保持独立。
- 直接 HTTP 验证回环资格、越权和 CSRF 错误顺序、固定长度与分块请求的大小边界、以及客户端提交的连接标头无法伪造监听器身份。合成凭据没有出现在 HTTP 响应或服务诊断中。
- 接收连接的本地地址来自监听器。固定 SDK 用对端地址和端口标识请求，对端标识重叠时拒绝基于回环地址授予资格。

此验收没有接入外部模型或邮件服务。直接 TLS 下的模型写入没有纳入此脚本。
