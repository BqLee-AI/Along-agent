### 两个真实路径缺陷及验证策略

1. 有数据的今日页在真实 Next 生产渲染中出现组件类型无效错误。原因是 Server Component 使用客户端 compound 组件成员；改为客户端展示边界并用 React `use` 读取服务端 Promise。真实生产失败是 Red；重建后五宽度成功内容及错误/空状态为 Green，没有用不模拟 Next 边界的静态渲染单测冒充回归证明。
2. 流式切换保住订阅但丢失新接纳会话的 URL。原因是 `history.replaceState` 传回 Next 内部 state，会跳过路由同步；改传 `null`，沿用 Next 支持的原生 history 集成。最终生产路径证明两次工作区导航和刷新均保留会话/运行定位，且没有第二次发送或订阅。
