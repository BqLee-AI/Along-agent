## 执行边界与证据要求

- 主执行者负责验收映射、隔离环境、真实浏览器旅程、产物/数据库核对与最终交付；没有默认的重复全量复验。
- 仅使用本任务专用安装、账户、PG、端口、卷和浏览器；配置与原始证据留在 D 盘仓库外。先核对安装归属，不启动或修改原安装。
- 只沿用获准模型连接配置；不回显或提交凭据、Cookie、CSRF、DSN、私有端点或 provider 请求标识。不读取或复制真实用户资料；文档材料自行生成。
- 浏览器故障注入只暂扣/丢弃本次指定请求或响应，不伪造 consumed、checkpoint、文档决议或任务状态。并发修订通过正式业务 API，不改数据库事实。
- 记录实际源码/构建版本、运行方式、请求次数、Run/批准/后继关系、任务状态与文件前后摘要。区分真实模型路径、受控网络故障和历史 CI。
- 发现行为缺陷先保留可复现证据，按既有合同修复并补对应覆盖；没有发现则不改运行代码。
- 验收记录写实际结果与未覆盖项，未执行不勾选。全部适用验收完成后才更新 tasks 3.2/3.3、执行 `openspec archive confirm-reminders-inline`，同步文档索引和使用说明，提交独立收口 PR。

实际补验、版本绑定与边界见[2026-11-02 验收记录](../verification/inline-reminder-verification-2026-11-02.md)；归档任务见[收口清单](../../openspec/changes/archive/2026-11-02-confirm-reminders-inline/tasks.md)。本计划描述执行方法，不代替实际结果。
