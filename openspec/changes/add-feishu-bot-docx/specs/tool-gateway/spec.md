## ADDED Requirements

### Requirement: 指定 Docx 的机器人只读授权

系统 SHALL 仅对显式指定单一直链 Docx 的新签名 Harness Run 授予 `feishu_docx_read`，并以可信 owner、会话、绑定代次、配置修订与目标资源冻结授权；只接受空参数。仅使用与绑定匹配的机器人应用身份，不回退到其他身份。

#### Scenario: 本地授权不满足

- **WHEN** owner、会话、机器人绑定、配置或文档不符合资格，或请求来自未获授的旧 Run
- **THEN** 不发起令牌或 Docx 请求，不披露私有结果。

#### Scenario: 飞书区分文档权限

- **WHEN** 同一合格 owner 分别请求本地允许的共享和未共享 Docx
- **THEN** 已共享文档仅在正文与前后观测版本有效且一致时返回带来源和覆盖标记的纯文本；未共享文档返回权限拒绝，且正文不进入模型、日志或回执。

### Requirement: 机器人只读结果的接受与再次披露

系统 SHALL 在调用前和结果接受时复核当前授权；私有正文仅在再次披露时仍具备本地资格才可回取。成功回执与恢复所需的私有副本不得明文落库，回取不得执行新的上游读取。

#### Scenario: 断开或取消赢过接受

- **WHEN** 本地断开、停用、替换绑定或 Run 取消在外部读取返回前提交
- **THEN** 不接受或披露迟到正文；重连不复活旧授权，已交付历史不改写。

#### Scenario: 重放与上游撤权不同

- **WHEN** 同一仍合格调用重放，随后飞书文档授权撤销并发起新调用
- **THEN** 重放复用原回执且没有新上游请求；新调用以当时的飞书授权结果为准，不以旧正文代替失败。
