## ADDED Requirements

### Requirement: 连接页启用与断开唯一公众查询

系统 SHALL 复用既有“连接应用”页面，为本人提供 Microsoft Learn 公众资料查询的空状态、显式连接、当前状态和断开动作。页面说明无需个人密钥、仅发送用户本轮显式提交的确切查询词到固定公开服务、结果为摘录；连接仅启用查询入口，不代表 Microsoft 登录或服务健康，不授予普通聊天、其他服务、资料、写入或既有 Run 新权限。沿用 design/20 §2–§4、§8–§9 的资格、Run 和执行生命周期合同。

#### Scenario: 从空状态完成真实查询

- **WHEN** 用户从未连接状态显式启用，选择会话“Microsoft Learn 查询”快捷入口并明确发送本轮查询
- **THEN** 服务端为合格新 Run 冻结连接代次和确切查询词，当前新 Run 才可使用唯一查询能力，回答依据真实返回结果并保留来源，运行事实仍能在既有历史中只读查看。

#### Scenario: 断开和刷新不会执行查询

- **WHEN** 用户断开，随后刷新、查看历史或重新登录
- **THEN** 页面显示真实连接状态，不自动连接、查询、重放消息或继续 Run；断开后新请求不可使用该服务。

#### Scenario: 连接写入仍需本人会话

- **WHEN** 请求未签名、跨 owner，或连接/断开动作缺少有效 Origin/CSRF 或携带额外配置
- **THEN** 拒绝更改，不产生远程请求，不接受浏览器或模型指定服务器、owner 或密钥。

### Requirement: 会话快捷入口仅提交本轮确切查询

系统 SHALL 复用会话输入框，以固定的“Microsoft Learn 查询”快捷入口承载本轮显式提交；发送前明确展示输入全文将作为查询词外发。该入口通过既有消息请求的可选 `microsoft_learn_query` 字符串提交输入全文，服务端 SHALL 校验其与本次 `raw_text` 完全相同、非全空白且不超过 500 个 Unicode 码点，原样冻结，不裁剪、改写、翻译或补全。缺省字段的普通消息不获得此能力，无效显式输入拒绝且不出站；不接受模型或上下文代填，不与私有资料快捷入口组合。字段是否存在及确切值 SHALL 纳入原请求幂等绑定，同键改词或改变显式查询资格均冲突，不重新冻结或扩权。具体输入合同见本 change design 的“本轮显式查询输入”。

#### Scenario: 选择和填写不等于发送

- **WHEN** 用户仅选择查询入口、填写或切换草稿，尚未点击发送
- **THEN** 不创建查询 Run、不冻结查询词、不发起外部请求；切换不改变历史 Run。

#### Scenario: 本轮输入边界与拒绝

- **WHEN** 用户发送含中文、空格和标点的有效显式查询，或提交空白、超过 500 码点、与消息正文不一致的字段
- **THEN** 有效输入原样冻结供工具消费，真正发出的 `query` 与该输入逐码点相同；无效输入本地拒绝且零 MCP 出站，不静默截断或退回普通聊天。

#### Scenario: 下一轮与恢复不继承查询授权

- **WHEN** 一次查询已发送，用户随后发送普通消息，或刷新、重登、查看历史、继续或恢复 Run
- **THEN** 输入框发送后回到普通聊天，下一轮不继承查询选择或冻结字段；原 Run 的幂等重放与恢复只保留原冻结值，不扩权或自动查询，新的查询须由用户再次显式提交。

#### Scenario: 幂等键不能把普通消息升级为查询

- **WHEN** 同一 owner/key 重交请求，但增加、删除或改变显式查询字段
- **THEN** 按原幂等冲突拒绝，零 MCP 出站；不将原普通 Run 升级、不替换原查询词，同绑定重放仅回原 Run。
