## ADDED Requirements

### Requirement: 连接页启用与断开唯一公众查询

系统 SHALL 复用既有“连接应用”页面，为本人提供 Microsoft Learn 公众资料查询的空状态、显式连接、当前状态和断开动作。页面说明无需个人密钥、仅发送查询词到固定公开服务、结果为摘录；连接不代表 Microsoft 登录或服务健康，不授予其他服务、资料、写入或既有 Run 新权限。沿用 design/20 §2–§4、§8–§9 的资格、Run 和执行生命周期合同。

#### Scenario: 从空状态完成真实查询

- **WHEN** 用户从未连接状态显式启用，并在新对话请求查询公开 Microsoft/Azure 资料
- **THEN** 当前新 Run 可以使用唯一查询能力，回答依据真实返回结果并保留来源，运行事实仍能在既有历史中只读查看。

#### Scenario: 断开和刷新不会执行查询

- **WHEN** 用户断开，随后刷新、查看历史或重新登录
- **THEN** 页面显示真实连接状态，不自动连接、查询、重放消息或继续 Run；断开后新请求不可使用该服务。

#### Scenario: 连接写入仍需本人会话

- **WHEN** 请求未签名、跨 owner，或连接/断开动作缺少有效 Origin/CSRF 或携带额外配置
- **THEN** 拒绝更改，不产生远程请求，不接受浏览器或模型指定服务器、owner 或密钥。
