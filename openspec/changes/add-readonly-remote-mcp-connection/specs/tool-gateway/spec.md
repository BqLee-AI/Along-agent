## ADDED Requirements

### Requirement: 固定公众远程 MCP 的单一只读查询

系统 SHALL 仅为已显式启用 Microsoft Learn 连接的新签名 delegation Harness Run 授予一个固定的公众资料搜索能力，并冻结本人连接代次。服务端固定目的地、工具名称和严格查询参数，不将远程发现转换为动态工具或授权；旧 Run 不随连接或部署扩权。职责与资格沿用 design/14 §1、§4.3 和 design/20 §2–§4。

#### Scenario: 已启用用户查询官方公开资料

- **WHEN** 合格新 Run 请求查询 Microsoft/Azure 公开资料
- **THEN** 服务端通过真实远程 MCP 发现固定搜索工具并调用，仅把实际返回的公开资料摘录和官方来源交回既有 Harness，不读取用户私有云端资料。

#### Scenario: 未允许的工具和参数

- **WHEN** 请求来自未启用、其他 owner、旧 Run 或失效资格，或工具/参数试图指定远程 URL、其他工具、写入或空搜索词
- **THEN** 本地拒绝且不产生 MCP 出站调用；发现到其他工具也不调用、不暴露为本 Run 能力。

### Requirement: 公众查询的当前资格与断开边界

系统 SHALL 在每次远程请求派发前及结果接受时复核 Run/attempt、当前本人资格和冻结连接代次，沿用事务外只读协调和同 invocation 的首次不可变结果。断开不撤回已派发请求或已交付历史，重连不恢复旧 Run；不产生自动重试或新 Run。公开结果不套用飞书私有文档的加密和撤回合同。

#### Scenario: 断开先于派发

- **WHEN** 断开已提交，或重连产生新代次，原 Run 尝试新查询或重交原调用
- **THEN** 拒绝且零新出站；新连接只能供后续合格新 Run 使用，历史事实保持只读。

#### Scenario: 断开或取消先于接受

- **WHEN** 读取在途时断开、停用账户或取消 Run 先于结果接受提交
- **THEN** 不接受迟到成功结果、不推进 Run；不得把在途请求已发出说成零调用或已撤回。

#### Scenario: 有效调用重放

- **WHEN** 同一仍合格 invocation 重交且已有接受结果
- **THEN** 返回原不可变结果，不再发现或调用 MCP，审计记录重放而非新的外部效果。

### Requirement: 远程工具与结果有界并可关联审计

系统 SHALL 限制发现工具、传输响应、结果数量和文本大小，只接受固定搜索结果的文本摘录及官方 HTTPS 来源；不执行返回链接，不把资料内容当作 system 指令或授权。接受结果和失败通过原 invocation/Run 与追加审计关联；超时、服务失败和协议或容量失败可区分，不伪造成功、完整全文或穷尽结果。结果事实沿用 design/20 §6。

#### Scenario: 来源和搜索覆盖

- **WHEN** 服务返回有效搜索结果或空结果
- **THEN** 返回实际摘录、来源和读取时间，并明确这是搜索结果而非全文；空结果只表示本次服务未返回匹配，不声称所有资料不存在。

#### Scenario: 超时和服务失败

- **WHEN** 真实调用超过本次有界 deadline，或远程 HTTP/MCP 服务失败
- **THEN** 保存有区分的失败分类和调用关联，不自动重试，不以旧搜索正文替代失败。

#### Scenario: 超界或不合约响应

- **WHEN** 工具发现或正文超出界限、需要未支持的分页、固定搜索工具不可用，或返回非文本/非官方来源/不合约内容
- **THEN** 返回有界协议或容量失败，不静默截断为完整结果，不跟随链接或重定向扩大出站范围。
