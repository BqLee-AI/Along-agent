## Why

设置中的技能页是占位入口。个人 Bot 已有角色说明、工具与资料范围，但一套工作步骤目前只能复制到各 Bot 配置，用户也无法针对一条消息选择使用同一套步骤。

## What Changes

- 在「设置 → 技能」创建、导入、编辑和停用本人文本技能。导入接受单个 `SKILL.md`，保存前展示解析出的内容与来源格式限制。
- 在个人 Bot 设置中分配技能。对话输入区列出该 Bot 可用的技能，用户可为一条消息选择一个技能并看到本轮使用的版本。
- 技能作为模型指令参与本轮上下文计量。工具、资料、连接和业务执行沿用现有授权合同。首版运行格式是单文件文本，完整技能目录与可执行资源另行设计。

## Impact

- Web 技能设置页、个人 Bot 设置和对话输入区。
- PostgreSQL 本人技能与版本、Bot 分配和 Run 冻结输入。
- TypeScript 技能用例和模型请求组装、仓颉 Harness 的原生 HTTP 产品入口及合同验证。

设计见 [design.md](design.md)，行为合同见 [personal-skills delta](specs/personal-skills/spec.md)。
