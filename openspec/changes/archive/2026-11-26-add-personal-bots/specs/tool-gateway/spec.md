## ADDED Requirements

### Requirement: Bot 的当前范围约束后续工具动作

对归属 Bot 的 Run，ToolGateway SHALL 以原冻结范围、当前 Bot 范围及当前用户和资源资格的交集裁决尚未获执行许可的动作。含工具、资料或目标的权限不得仅凭旧审批、恢复快照或模型指令补足。已发生的效果和已接受回执 SHALL 如实保留；事务外在途或未知效果遵从既有合同。参见 [设计 §4](../../design.md#4-当前资格与效果边界)。

#### Scenario: 旧审批不能覆盖撤权

- GIVEN 某 Bot 的 Run 已产生一条指向受管资料的待批准操作
- WHEN 用户缩小该 Bot 的范围后确认或继续该 Run
- THEN 在撤权前尚未取得执行许可的动作不能取得许可或产生写入，原预览及已接受结果保持可追溯

#### Scenario: 扩权不会改变已接纳 Run

- WHEN 用户给 Bot 增加工具或资料，而旧 Run 继续执行
- THEN 旧 Run 无法使用原冻结范围以外的能力，新的合法 Run 才可使用新增范围

#### Scenario: 撤权与执行并发

- WHEN 配置收窄与动作取得执行许可并发发生
- THEN 以两者持久提交顺序裁决；先提交的撤权阻止取得许可，已取得的许可按现有效果合同收尾，不把已发生或未知的效果说成未执行

#### Scenario: 撤权后不再向模型披露受限资料

- WHEN Run 在资料撤权后尝试通过已存观察、来源回读或恢复上下文把受限资料重新交给模型
- THEN 服务阻止该披露，既有历史仍按原有用户只读权限可查
