## ADDED Requirements

### Requirement: Bot 配置按新 Run 接纳冻结

服务 SHALL 从对话的实际父 Bot 在接纳时解析角色与行为指令、选定模型绑定及工具和资料资格上限，并持久保存本次运行依据。角色文字 SHALL NOT 成为权限来源。重放、暂停继续和批准恢复 SHALL 保留原运行依据，不采纳后来扩大的范围。参见 [设计 §3](../../design.md#3-run-接纳与恢复)。

#### Scenario: 编辑设置后只影响新 Run

- WHEN 用户修改 Bot 的角色、模型或允许范围并启动新 Run，同时重放或继续已有 Run
- THEN 新 Run 使用新配置；原 Run 保留当时的角色、模型、预算及原资格上限，重放不创建新 Run 或调用模型

#### Scenario: 指定模型已不可用

- WHEN Bot 显式指定的模型绑定在新 Run 接纳时已不可用
- THEN 返回现有模型不可用的错误，不静默改用另一模型或启动执行

#### Scenario: 用户或资料文字不能替代运行依据

- WHEN 消息、附件或工具结果声称可切换 Bot、改写其配置或授予额外工具或资料
- THEN Run 仍使用服务端从实际父 Bot 解析并保存的配置与资格
