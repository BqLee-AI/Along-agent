# 设计摘要

完整合同和取舍见 [design/22](../../../docs/design/22-model-provider-settings.md)。配置归用户；Run 接纳由 conversations 在同一事务解析 owner、有效选择和不可变版本，持久安全展示快照，恢复只读原版本。配置写入与网络同步分开，网络之后须再次比较版本。密钥与数据库分离、按 owner/provider 认证加密；删除/清除使旧凭据不可再用。部署级导入必须明确目标 owner，旧 Run 不借当前默认恢复。

SDK 只是单次传输实现候选，必须先证明出站连接控制、精确发送前计量、真实流终止、无隐式重试及原工具/预算语义；本 change 不假定 SDK 默认满足这些约束。各阶段状态和独立证据见任务清单。
