Issue: #70

## Why

#67、#68、#69 分别交付本机生命周期、正式账户和会话历史，但旧 Web 的页面与交互不足以承载正式日常使用。Web 新任务仍暴露执行引擎，复杂组件混合展示与执行编排。本变更以 shadcn/ui + Tailwind CSS 完整重构 Web 的信息架构、应用布局、全部页面和前端职责，不以旧 Demo 的配色、布局或组件结构为保留目标；复用的是已交付后端能力及业务/安全合同，而非旧页面实现。

## What Changes

- 明确采用 shadcn/ui、Radix/new-york 基础风格与 Tailwind CSS v4，组件源码纳入既有 Web 维护；以“蓝墨任务书桌”的排版、语义色和密度重建，不另起平行应用或共享 UI 平台。具体依赖版本与 RSC 兼容性由实施验证。
- 以“创建提醒 / 处理资料”明确选择执行路径，不由模型分派、不在模型不可用时静默切换；资料选择呈现真实有限授权和受管副本说明。
- 重新设计桌面侧栏和窄屏 Sheet，重建今日、对话/历史/Run、提醒确认、文档批准、提醒任务/详情、活动及全部账户页面；活动采用任务范围索引与单任务事件分页，不伪造全局全量时间线。
- 区分提醒确认与文档批准，完整冻结预览不可由摘要代替；批准只授权，返回原 Run 后须显式继续。状态只来自 Run、决议与工具效果，不把模型说辞作为保存证据。
- 精确反馈认证、权限、依赖、冲突、unknown、取消及断流；查看、刷新、回退与重登只读，不自动补发副作用。
- 重新组织前端 View、功能级 hook/controller 和 Model/数据访问，重建复杂交互并复用有效合同与纯逻辑；统一生命周期归属，不新增状态事实表、SSE 词表、全局状态平台或空转发层。
- 主要页面具备真实加载、空、禁用、分页、部分失败、字段错误与状态播报，支持键盘和约 375px 窄屏，精确批准内容及长路径完整可达。

## Impact

影响整个 Web 展示与交互层、组件/样式基础、页面组装、数据访问和必要依赖/单一 bun.lock；按完整切片交付，最终移除旧视图和样式，不保留平行 UI。字段核对见 design.md §6.1：本方案不要求新增 DTO，缺少标题、历史工作区名或不可继续原因时诚实呈现已有事实，不补造。同步长期 design、PRD、API 和索引是合同交付任务；本次仅准备 OpenSpec 材料，不安装依赖或改运行代码。

## 非目标 / Deferred

不重做启动、认证机制和历史后端；账户与历史的前端页面在重构范围内。不做 R2、新 Agent、任意宿主目录管理、自动批准/恢复、第二执行状态机、审计平台、独立组件库发布平台或无当前用途的新依赖；shadcn/ui 与 Tailwind CSS 不属于排除项。不修改 provider、模型路由、私有配置、认证密钥、owner、原登记、原资料或已合并迁移。不以准备材料关闭 #70 或 #66，不把旧模块证据冒充重构后的跨模块验收。
