# 设计导航（Proposed）

完整设计以 [docs/design/23-r3-short-term-memory-and-compact.md](../../../docs/design/23-r3-short-term-memory-and-compact.md) 为真源；本 change 只表达拟议行为增量，不改变有效 specs 或宣称已有实现。证据及适用边界见 [R3 阶段 0](../../../docs/verification/r3-stage-zero-2026-11-13.md)。

新 Run 的安全点暂停与批准等待分别建模：前者等待当前模型流结束、已接受工具结果有真实裁决后才可冻结；后者仍绑定原批准和决议。同一 Run 继续须重新检查当前执行资格、保留原预算和事实；普通 checkpoint、unknown 工具结果、取消或终态不因此可恢复。此能力不是任意进程崩溃恢复。

手动和自动触发使用同一隔离摘要过程，输入是带可信来源及确定覆盖边界的数据而非高权限指令，输出是有来源、可校验的派生内容而非事实替代。成功需与取消及会话消息竞争原子裁决；失败保留原上下文和状态，不能伪报成功。容量、预算与 provider usage 如实核算，未知不充零；没有可靠窗口及计量时不假定百分比阈值。

新合同下不再用固定 63 条及相应引用限制裁剪新 Run，不能因此移除独立容量门或重写旧 Run/批准恢复。显式记住及 compact 可产生 owner 级记忆，原始消息和真实事件为权威，字面与 pgvector 是派生检索而非事实来源；精确编号优先，相关性不足允许无答案。MVP 不以代表性质量评测或调优作为合并前置，参数不得冒充质量保证；具体验收边界见 design/23 §8。
