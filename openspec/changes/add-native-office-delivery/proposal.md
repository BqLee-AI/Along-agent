# 原生会话资料处理与交付

## Why

用户需要在对话中处理明确选中的纪要和任务表，取得可复算的真实文件及按本人原话建立的提醒，不必先登记宿主目录或连接办公平台。

Spec：`docs/design/24-native-office-delivery.md` §1–§6。

## What Changes

- 支持本人会话内的私有附件暂存、显式接纳、撤销及已接受产物下载；旧请求和旧 Run 不扩权。
- 正式仓颉在冻结资格内读取资料，服务端确定性计算任务 CSV 并事务提交可下载报告、汇总及真实回执。
- 文件与明确委托的一次站内提醒分别报告真实结果；仅补提醒信息不重做已交付文件。
- 使用 Along 自有密钥保护必须持久化的私有正文；停止新接纳不删除历史读取、撤销和清理能力。

## 非目标 / Deferred

不接入飞书或其他连接器，不建立跨会话资料库，不支持通用代码执行、自动发送、第三方任务同步或任意 CSV 列映射。

## Impact

- `conversations`：草稿资料、Run 接纳、历史及下载。
- `agent-runtime`、`tool-gateway`：冻结资格、私有恢复、确定性分析、产物和提醒回执。
- 前向数据库迁移、Web/BFF、正式仓颉消费者及独立真实路径验收。
