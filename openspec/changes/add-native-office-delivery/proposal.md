# 原生会话资料处理与交付

## Why

用户需要在对话中处理明确选中的纪要和任务表，取得可复算的真实文件及按本人原话建立的提醒，不必先登记宿主目录或连接办公平台。

Spec：`docs/design/24-native-office-delivery.md`。

## What Changes

- 对话页独立选择资料，本地验证与计算，下载同一确定性结果生成的 Markdown 与 CSV。
- 用户可明确选择让已配置的默认模型生成纪要摘要；只发送纪要文本，不需要文件服务、工具链或运行快照。
- 提醒由用户另行明确发送，复用原有对话提醒；文件和提醒各自成功或失败。

## 非目标 / Deferred

不保存服务器附件、产物或私有运行状态；无历史重新下载和办公续办。不接入办公连接器，不支持通用代码执行、自动发送、第三方任务同步或任意 CSV 列映射。

## Impact

- `conversations`：Web 页面资料面板；保留既有消息、Run、工作区和提醒合同。
- `model-providers`：本人默认模型的有界、无工具纪要摘要；不写资料或运行数据。
